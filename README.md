使用方法：
你需要在仓库Settings →Secrets and variables →Actions里，
配置 NODE_LINK、DISCORD_TOKEN、EMAIL、TG_BOT_TOKEN、TG_CHAT_ID

配置完成后在Actions中启动


NODE_LINK（代理节点链接,支持vless、、wmess、trojan和sockes5等singbox协议。选填，但建议填写固定ip续期。）


DISCORD_TOKEN（Discord token。必需，可向ai询问如何获取）


EMAIL（通知邮箱。选填。）


TG_BOT_TOKEN（tg通知，与TG_CHAT_ID配对使用。选填,可向ai询问如何获取。）


TG_CHAT_ID（tg通知，与TG_BOT_TOKEN配对使用。选填,可向ai询问如何获取。）
